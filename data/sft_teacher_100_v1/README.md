# SFT teacher 100 v1

2026-10-14：取消50/100数据量对照，冻结100条轨迹与此前41条SFT版本比较。

## 数据组成

|主要类别|条数|定义|
|---|---:|---|
|一次检索即可证据齐全|25|一次工具调用后应立即停止；不一定只有一个逻辑关系|
|多跳|45|取得中间实体后继续补齐关系；包含少量三次检索恢复|
|干扰|20|核对同名实体、年份、作品版本、角色或数值，选择正确证据|
|证据不足|10|明确限定的三文档语料保留首跳、缺少目标关系，定向查询后停止并弃答|

100条来自100个不同训练题。80条为未修改的教师轨迹，10条为受控恢复版本，10条为受控缺证据版本；同一题的自然版与干预版没有同时进入训练集。

恢复是交叉标签，不在100条之外：4条无效引用、2条未知动作、2条空查询、2条临时工具失败。另保留6条自然检索改写恢复。错误动作只做上下文，不做监督目标；工具暂时失败时，合法的搜索请求和重试可监督。

109条已接受教师候选来自140条生成记录。教师为当前助手，实际调用固定检索器/控制器，生成后按证据审阅；不是独立人工审定。没有把标准答案或标准证据作为生成输入。筛选偏向原底座失败题，不代表Hotpot总体分布。

## 核验结果

- 100条轨迹、280个监督动作、16,890个监督token；最长2717token。
- 实际控制器重放、语料及轨迹哈希、引用可见性、搜索预算检查通过。
- 无重复的成功查询；工具暂时失败后的同查询重试单独记录。
- 输入、工具反馈、被注入的错误动作及padding不参与目标loss；正确动作及EOS参与监督。
- 语义证据链由助手审阅；标准文档ID覆盖不是语义可靠性证明。
- 10条弃答使用小型受控语料，不能称为自然Hotpot无答案样本，也不能据此声称开放搜索安全弃答。

`train.jsonl`保存消息与来源；`manifest.json`保存选择及类别；`traces/`保留实际动作与反馈；`controlled_corpora/`保存缺证据环境；`tokenized.jsonl`为训练输入；`validation_report.json`为机械核验报告。
