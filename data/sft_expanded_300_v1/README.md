## 来源

新增200条父轨迹来自38条当前助手教师示范与162条经过当前助手证据审核的学生候选。学生候选由冻结的100条SFT适配器生成，而非原始底座：`outputs/sft_teacher100_20261013T162355Z_1ec152e7/adapter`。

400道新训练候选按Hotpot难度采样（80 easy、160 medium、160 hard）。实际新教师批次生成50条、接受38条；学生候选审核195条、接受172条，从中按难度与检索次数分层选择162条。最终新增难度：easy42、medium75、hard83。筛选并非任务总体的随机样本，不能用接受率评价模型泛化。

## 行为与题型

主类别：一次搜索足够84、多跳127、干扰69、缺证据20。搜索次数分布为1次99、2次189、3次12；检索次数不等于逻辑跳数。

30条恢复包括：未见引用4、近似但错误的长引用ID10、多JSON对象5、未知动作2、空查询2、临时检索故障7。新增20条优先使用较长上下文，最长恢复训练序列2551 token。错误JSON/错误动作不监督；合法请求遭遇临时工具故障可监督，随后保留真实失败反馈与恢复。工具失败后重试同一查询不算重复成功搜索。

20条缺证据均使用可逐篇检查的三文档封闭语料：保留中间实体关系，移除末跳关系并加入无关文档。新增10条使用不同干扰文档对。不得将它们解释为自然Hotpot不可回答题，也不得将普通检索漏召回标成无答案。

## 文件

- `train.jsonl`：完整对话与来源、审核、监督索引。
- `tokenized.jsonl`：只监督指定正确动作及EOS；用户问题、工具反馈、错误动作均屏蔽。
- `traces/`：新增200条在实际控制器上的重放。
- `actor_source_snapshots/`：新增200条原始生成记录的逐字节副本；没有修改原始输出。
- `controlled_corpora/`：新增10条缺证据样本的完整小语料。
- `manifest.json` / `validation_report.json`：冻结哈希、构成和验证结果。
- 原100条的轨迹及语料仍依赖同仓库`data/sft_teacher_100_v1`与旧教师批次，不复制修改。

在项目根目录、search-agent环境中运行：

```powershell
python .\scripts\validate_sft_expanded_300.py
python .\scripts\check_sft_batch.py --data-dir .\data\sft_expanded_300_v1
```
