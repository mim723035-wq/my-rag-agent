# 针对错误归因的新增100条SFT（最终版）

2026-10-14：从新分片`hotpot_shards_v1/shard_01/sample_300_v1`生成并审核100个不同父题的教师示范。由当前Codex助手编写动作，使用真实本地BM25和控制器执行；不是Qwen模型自采样。教师精确模型版本不可取得，生成与审核由同一助手完成，非独立人工审定。

## 训练入口

最终有效文件为本目录`train.jsonl`与`tokenized.jsonl`，不要使用`data/sft_targeted_shard_100_v1/train.jsonl`草稿。

| 主行为 | 条数 |
|---|---:|
| 查询推进（含多跳及检索改写恢复） | 30 |
| 年份/身份/作品/共同属性等条件核验 | 25 |
| 停止判断：缺末跳时继续 / 证据充分时停止 | 15 / 10 |
| 受控引用/格式错误恢复 | 15 |
| 受控缺失关系，拒绝猜测 | 5 |

这些是互斥的主标签，语义行为可以重叠；检索次数并非逻辑跳数。实际搜索分布：一次44、两次55、三次1。15条“缺关系继续”均实际检索至少两次；10条“足够即停”均一次搜索。

最终来源：70条保留教师动作、10条修订多余搜索的教师轨迹、15条受控恢复、5条受控缺证据。恢复为12条近似长ID错误、3条多JSON对象错误，实际触发控制器拒绝后再提交正确动作，错误动作只作上下文。缺证据用完整可检查的三文档小库，不能称为自然Hotpot不可回答题。

针对归因的实例包括：

- Ryan Castro → Port Washington → **Nassau County**，核对县而非把城市作答。
- 作品与身份条件之外进一步核验出生年份、角色或职业，例如Liverpool 8的共同制作者及1951出生条件、导演与演员区分。
- John Cullum两部获奖音乐剧，确认哪个为screwball comedy后回答另一部，避免取第一个候选。
- Pound Shop Wars → Caroline Aherne → Gogglebox，核对Channel 4及2013—2016叙述时间。
- 用户问题中的关键关系已全部支持后结束；不会为了演示多跳强行增加搜索。

## 构造与来源审计

共尝试132个候选题，完成116条原始教师回答，最终导出100条。未导出的记录包含未解决、题意/前提问题、标注暴露草稿和备用记录，不能将32条都称为模型答错或质量拒绝。

初始查看文件时，池索引0、1、2的标准标注曾被展示。v1草稿未通过最终来源审核，其原始`gold_used_during_generation=false`声明不准确，已在草稿manifest里纠正说明。最终v2排除这3个父题，并以新的题目替换。原始轨迹没有改写；不把草稿冒充盲生成记录。

最终100条生成时不提供标准答案/支持标注，后续审核依据实际返回全文；标准标注可以用于审核，但不以EM匹配替代语义审核。筛掉了电影/书籍副标题混淆、主体或类别不唯一、给定年份与证据不符等候选。检索失败不自动等于原库不可回答。

原始教师记录保存在同仓库`data/sft_targeted_shard_100_v1/teacher_raw`；本目录`traces`是最终实际重放。`review_decisions.json`保留逐题所审核全文、主标签与修订；`selection_plan.json`保留替换理由。依赖原始记录的跨目录引用已保留哈希，不能删除v1原始轨迹目录。
